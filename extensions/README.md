## Légende

- **Nom du ZIP** : nom exact de l’archive présente dans ce dossier ; « — » signifie qu’aucune archive correspondante n’y est conservée.
- **Type** (déduit du nom de l’archive) : `TradFix` = traduction française, `ModFix` = correctif, `Mod` seul = mod personnalisé.
- **ID** : identifiant Steam Workshop ; « Local » = package sans page Workshop (mods personnalisés Skoltroy et packages locaux).
- **Version** : `TradFix 1.0` = version du package de traduction ; `Mod x.y` = `modVersion` déclarée dans l’`About.xml` du package ; « Version non déclarée » / « Source non déclarée » = aucune version indiquée.
- **RW** = versions de RimWorld déclarées dans `About.xml` (listées par ordre croissant).
