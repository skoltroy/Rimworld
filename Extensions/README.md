# Extensions de mods RimWorld

Ce dossier contient des extensions pour des mods RimWorld publiés sur Steam :

- corrections d’erreurs liées au chargement des mods ;
- traductions françaises complètes ou complémentaires aux traductions existantes.
- 119 French TradFix par ID et trois French TradFix locaux (BTD Gravship Descriptions, le mod sniper sans ID Workshop et Royalty). Les paquets existants reposent sur les copies du 18/11/2026 ; les ajouts du 20/11/2026 et du 21/11/2026 sont documentés ci-dessous. Ressources et conditions de chargement à réviser après chaque mise à jour source.
